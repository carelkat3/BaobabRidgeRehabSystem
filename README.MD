## How to Build and Run
1. Clone the repository to your local machine.
2. Open `BaobabRidgeRehabSystem.sln` in Visual Studio (requires .NET 8.0 or newer).
3. Build the solution (`Ctrl + Shift + B`).
4. Run the application (`F5` or the Start button).

## Features
* **Add Animal:** Add a new animal with automatic status and housing calculation based on Recovery Score.
* **View Animals:** View all records in a read-only data grid.
* **Update Animal:** Search for an animal by ID or grid selection and update its details.
* **Delete Animal:** Remove a selected record from the system safely.
* **Summary Report:** Generate a statistical summary of all animals currently in care.

## File Formats
* **animals.txt:** A pipe-separated (`|`) plain text file containing the animal records (ID | Name | Species | Age | Score | Status | Housing Unit). It uses UTF-8 encoding with no headers or blank lines.
* **summary.txt:** A plain text report generated by the application at runtime containing total counts, averages, and a per-status breakdown.
